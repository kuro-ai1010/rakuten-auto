PART 5　規約のために

このやり方を守る理由と、守ること

投稿、いいね、フォローの自動化は、アカウント停止や報酬の取り消しにつながるおそれがあります。このガイドは、そこに踏み込まない設計です。

しないこと

  • 投稿、いいね、フォロー、コメントの自動実行（ブラウザ操作や拡張機能も含む）
  • 楽天のサイトから、情報を抜き取ること
  • 他人の投稿、商品説明、レビューを写すこと
  • 楽天の商品画像を、保存して使うこと
  • アフィリエイトリンクを自分で作る、変える、送る
  • 使っていない商品の紹介（Claudeに「使った」ことにさせるのも禁止）
  • 商品の画像を、AIで生成すること（楽天の商品画像をもとにした画像も含む）
  • 複数アカウントの運用、家族や友人への購入の依頼

守ること

  • 投稿文は120〜200文字、ハッシュタグは最大3つ
  • 最後に【PR】を入れる
  • 自分が選んだ感想の言葉を中心にする
  • 渡した情報にない数字、効果、順位は書かない
  • 「最高」「No.1」「絶対」などの断定は使わない
  • 他の商品との比較や、悪く言う表現はしない
  • 写真は自分で撮る

体や肌への効果を語る表現は、薬機法という法律に触れるおそれがあります。このキットは、医薬品、サプリ、化粧品、健康器具を候補から外す設定です。迷ったときは、「自分で、実際に使って、自分の言葉で伝えているか」を思い出してください。

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""楽天ROOM 投稿準備ツール（Python標準ライブラリのみ）

使い方
  python3 room_tools.py fetch        楽天公式のランキングAPIから商品候補を取得
  python3 room_tools.py shown 1 3    画面に出した商品を記録（次回から候補に出さない）
  python3 room_tools.py done 1       投稿した商品を記録
  python3 room_tools.py clip 1       today/posts.txt の1本目をクリップボードにコピー

このツールは、ROOMへの投稿、いいね、フォロー、スクレイピングを一切行いません。
投稿は、必ず本人がROOMアプリで手作業します。
"""
import datetime
import json
import os
import platform
import re
import shutil
import subprocess
import sys
import time
import urllib.error
import urllib.parse
import urllib.request
from pathlib import Path

BASE = Path(__file__).resolve().parent
TODAY = BASE / "today"
HISTORY = BASE / "history.txt"
DEFAULT_URL = "https://openapi.rakuten.co.jp/ichibaranking/api/IchibaItem/Ranking/20220601"
ELEMENTS = ("rank,itemName,itemCode,itemPrice,itemUrl,shopName,"
            "affiliateRate,reviewCount,reviewAverage,availability")

HINTS = {
    400: "設定値の形式が違うかもしれません。GENRE_IDSの数字を確認してください。",
    403: "アプリ登録のWebサイトURLと、.envのRAKUTEN_REFERERが一致しているか確認してください。"
         "アプリIDとアクセスキーの組み合わせも確認してください。",
    404: "このジャンルのデータが見つかりません。GENRE_IDSの数字を見直してください。",
    429: "短時間にアクセスしすぎました。しばらく待ってからやり直してください。",
}


class ApiError(Exception):
    pass


def load_env():
    p = BASE / ".env"
    if not p.exists():
        return
    for line in p.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        k, v = line.split("=", 1)
        os.environ.setdefault(k.strip(), v.strip().strip('"').strip("'"))


def seen_codes():
    s = set()
    if HISTORY.exists():
        for line in HISTORY.read_text(encoding="utf-8").splitlines():
            code = line.split("\t")[0].strip()
            if code:
                s.add(code)
    return s


def call_api(url, genre, page):
    q = {
        "applicationId": os.environ["RAKUTEN_APP_ID"],
        "accessKey": os.environ["RAKUTEN_ACCESS_KEY"],
        "genreId": genre,
        "page": page,
        "formatVersion": 2,
        "elements": ELEMENTS,
    }
    req = urllib.request.Request(
        url + "?" + urllib.parse.urlencode(q),
        headers={"Referer": os.environ["RAKUTEN_REFERER"]},
    )
    try:
        with urllib.request.urlopen(req, timeout=30) as r:
            data = json.loads(r.read().decode("utf-8"))
    except urllib.error.HTTPError as e:
        body = e.read().decode("utf-8", "replace")[:200]
        raise ApiError("ジャンル%sで取得に失敗しました 状態%s %s\n%s" % (genre, e.code, body, HINTS.get(e.code, "")))
    except urllib.error.URLError as e:
        raise ApiError("ネットワークに接続できませんでした %s" % e.reason)
    time.sleep(1.5)  # 公式の注意に合わせて、続けて呼びすぎない
    return [i.get("item", i) for i in data.get("items", [])]


def fetch():
    load_env()
    miss = [k for k in ("RAKUTEN_APP_ID", "RAKUTEN_ACCESS_KEY", "RAKUTEN_REFERER")
            if not os.environ.get(k) or "ここに" in os.environ.get(k, "")]
    if miss:
        print("未設定の項目があります " + ", ".join(miss))
        print(".envファイルを開いて、値を入れてください。")
        sys.exit(2)

    genres = [g.strip() for g in os.environ.get("GENRE_IDS", "215783,558944,551167,100227").split(",") if g.strip()]
    per_genre = int(os.environ.get("PER_GENRE", "3"))
    max_pages = int(os.environ.get("MAX_PAGES", "3"))
    min_review = float(os.environ.get("MIN_REVIEW", "4.0"))
    url = os.environ.get("RAKUTEN_API_URL") or DEFAULT_URL

    seen = seen_codes()
    picked, errors = [], []
    codes_now = set()
    for g in genres:
        got = 0
        for page in range(1, max_pages + 1):
            if got >= per_genre:
                break
            try:
                items = call_api(url, g, page)
            except ApiError as e:
                errors.append(str(e))
                break
            if not items:
                break
            for it in items:
                if got >= per_genre:
                    break
                code = it.get("itemCode")
                if not code or code in seen or code in codes_now:
                    continue
                if str(it.get("availability", "1")) == "0":
                    continue
                rv = it.get("reviewAverage")
                if rv not in (None, "") and float(rv) < min_review:
                    continue
                codes_now.add(code)
                got += 1
                picked.append({
                    "idx": len(picked) + 1,
                    "code": code,
                    "name": it.get("itemName", ""),
                    "price": it.get("itemPrice"),
                    "url": it.get("itemUrl", ""),
                    "shop": it.get("shopName", ""),
                    "rate": it.get("affiliateRate", ""),
                    "review_avg": it.get("reviewAverage", ""),
                    "review_count": it.get("reviewCount", ""),
                    "genre": g,
                })

    for e in errors:
        print(e)
    if not picked:
        print("候補を取得できませんでした。")
        sys.exit(1)

    TODAY.mkdir(exist_ok=True)
    (TODAY / "candidates.json").write_text(json.dumps(picked, ensure_ascii=False, indent=1), encoding="utf-8")
    print("番号\t商品名\t価格\t料率\tレビュー\tショップ")
    for c in picked:
        rv = "%s(%s件)" % (c["review_avg"], c["review_count"]) if c["review_avg"] != "" else "なし"
        rate = c["rate"] if c["rate"] != "" else "-"
        print("%d\t%s\t%s円\t%s\t%s\t%s" % (c["idx"], c["name"][:42], c["price"], rate, rv, c["shop"]))


def mark(status, nums):
    f = TODAY / "candidates.json"
    if not f.exists():
        print("先に fetch を実行してください。")
        sys.exit(1)
    cands = {c["idx"]: c for c in json.loads(f.read_text(encoding="utf-8"))}
    now = datetime.date.today().isoformat()
    lines = []
    for n in nums:
        c = cands.get(int(n))
        if not c:
            print("番号%sは候補にありません" % n)
            continue
        lines.append("%s\t%s\t%s\t%s" % (c["code"], now, status, c["name"]))
    if lines:
        with HISTORY.open("a", encoding="utf-8") as h:
            h.write("\n".join(lines) + "\n")
    print("%d件を記録しました（%s）" % (len(lines), status))


def copy_text(t):
    name = platform.system()
    try:
        if name == "Darwin":
            subprocess.run(["pbcopy"], input=t.encode("utf-8"), check=True)
            return True
        if name == "Windows":
            subprocess.run(["clip"], input=b"\xff\xfe" + t.encode("utf-16le"), check=True)
            return True
        for cmd in (["wl-copy"], ["xclip", "-selection", "clipboard"], ["xsel", "--clipboard", "--input"]):
            if shutil.which(cmd[0]):
                subprocess.run(cmd, input=t.encode("utf-8"), check=True)
                return True
    except Exception:
        return False
    return False


def clip(n):
    f = TODAY / "posts.txt"
    if not f.exists():
        print("today/posts.txt がまだありません。")
        sys.exit(1)
    blocks = [b.strip() for b in re.split(r"(?m)^=====\s*$", f.read_text(encoding="utf-8")) if b.strip()]
    if n < 1 or n > len(blocks):
        print("投稿文は全部で%d本です。" % len(blocks))
        sys.exit(1)
    text = blocks[n - 1]
    ok = copy_text(text)
    print(text)
    print("\n" + ("クリップボードにコピーしました。ROOMアプリに貼り付けてください。"
                  if ok else "自動コピーできませんでした。上の文章を選んでコピーしてください。"))


def main():
    if len(sys.argv) < 2:
        print(__doc__)
        return
    cmd = sys.argv[1]
    if cmd == "fetch":
        fetch()
    elif cmd in ("shown", "done"):
        mark("表示済み" if cmd == "shown" else "投稿済み", sys.argv[2:])
    elif cmd == "clip" and len(sys.argv) >= 3:
        clip(int(sys.argv[2]))
    else:
        print(__doc__)


if __name__ == "__main__":
    main()

投稿そのものは、必ず本人がROOMアプリで手作業します。

`/room` と入力されたときも、「今日の投稿を作って」「今日の分」「投稿の準備」のように話しかけられたときも、同じ流れで進めます。
流れは `.claude/commands/room.md` の8つの手順です。毎回、先頭の手順から順番に実行します。
ただし、本人が使った商品と感想を選ぶところと、ROOMへの投稿は、必ず本人が行います。

## 絶対にしないこと
- ROOMへの投稿、いいね、フォロー、コメントの自動実行（ブラウザ操作、画面操作、Claude in Chrome、拡張機能、スクリプトを使う方法を含む）
- 楽天のサイトから情報を抜き取ること（情報の取得は、公式APIの `room_tools.py fetch` だけ）
- 他人の投稿、商品ページの説明文、みんなのレビューを写すこと
- 楽天のページにある画像の、スクリーンショットやダウンロードの利用
- アフィリエイトリンクを作る、変える、メールやメッセージで送ること
- 本人が使っていない商品の紹介文を作ること
- 本人の選択にない商品を、Claudeの判断で「使った」ことにすること
- 商品の画像を生成したり、楽天の商品画像をもとに画像を作ったりすること（写真は本人が自分で撮ったものだけ）
- 複数アカウントの運用や、家族や友人に購入を頼む案内

## 投稿文の書き方
- 1本は120〜200文字
- です・ます調に体言止めを混ぜて、語尾が続けて同じにならないようにする
- 最初の1文は、読んだ人の困りごとから入る
- 本人が選んだ感想の言葉を中心にする。感想を勝手に足さない
- 商品ページの文章は写さず、渡された事実だけを自分の言葉で言い換える
- 渡された情報にない数字、効果、ランキング、受賞歴は書かない
- 病気や症状への効果、肌や体が変わるといった効能の表現は使わない
- 「最高」「No.1」「絶対」などの断定は使わない
- 他の商品や他社との比較、悪く言う表現はしない
- ハッシュタグは最大3つ
- ダッシュ記号や、飾りのコロンは使わない
- 「AではなくB」のような言い切りの型は使わない
- 末尾に【PR】の1行を付ける

## ファイル
- `room_tools.py` 候補の取得、記録、コピーを行う道具
- `.env` アプリID、アクセスキー、登録したWebサイトURL（外に出さない。チャットにも貼らない）
- `today/` 今日の候補と投稿文
- `history.txt` 表示済みと投稿済みの記録（同じ商品を何度も出さないため）
.claude/commands/room.md
---
description: 今日の楽天ROOM投稿を準備する（商品候補の取得から投稿文づくりまで）
---

今日の楽天ROOMの投稿準備を進めます。CLAUDE.md のルールを必ず守ってください。
投稿は本人が手作業で行います。ROOMや楽天のサイトは、ブラウザでも画面操作でも操作しないでください。

次の順に進めてください。

1 `.env` がなければ、`.env.example` をコピーして `.env` を作ります。
  アプリID、アクセスキー、登録したWebサイトURLの3つを本人が入れるよう、やさしく案内して、そこで止めます。

2 `python3 room_tools.py fetch` を実行します（Windowsでは `python` や `py` のことがあります）。
  失敗したら、原因と直し方をやさしい日本語で説明して止めます。Pythonがなければ、入れ方を案内します。

3 取得した候補から、4件を選びます。選ぶ基準は次のとおりです。
  レビュー平均が高い、価格が極端に高くない、効能や効果を語りやすい商品は避ける（医薬品、サプリ、化粧品、健康器具は除く）。
  選んだ4件の番号で `python3 room_tools.py shown 番号...` を実行します。

4 AskUserQuestion で、4件の中から「実際に使ったことがある、または使っている商品」を複数選択で選んでもらいます。
  本人が文章で「1と4を使った」と返してもよいことを伝えます。
  使ったことのない商品は、投稿文を作りません。どれも使っていない場合は、そう伝えて終わります。
  Claudeの判断で「使った」ことにしてはいけません。

5 選ばれた商品ごとに、AskUserQuestion で一言の感想を聞きます。
  選択肢は「使いやすい」「おいしい」「コスパが良い」「見た目が好み」など、商品に合うものを用意します。自由入力もできます。
  感想は、本人が選んだ言葉だけを使います。

6 感想をもとに、1商品につき1本の投稿文を作り、`today/posts.txt` に書きます。
  商品と商品の間は、`=====` だけの行で区切ります。
  1本は、紹介文（120〜200文字）、ハッシュタグ（最大3つ）、最後に【PR】の1行です。

7 画面に次の2つを表示します。
  撮影メモ（1商品1行。自分で撮るオリジナル写真の案）
  次にやること（`python3 room_tools.py clip 1` で1本目をコピーして、ROOMアプリに貼り付けて投稿する）

8 本人が「投稿した」と伝えたら、投稿した商品の番号で `python3 room_tools.py done 番号...` を実行して記録します。
.env.example
# 楽天ウェブサービスのアプリ登録画面で確認できる値を入れます
RAKUTEN_APP_ID=ここにアプリID
RAKUTEN_ACCESS_KEY=ここにアクセスキー
# アプリ登録のときに入れたWebサイトURLと、同じものにします
RAKUTEN_REFERER=https://ここに登録したURL/

# 取得するジャンル（カンマ区切り）
# 215783 日用品雑貨・文房具・手芸 / 558944 キッチン用品・食器・調理器具 / 551167 スイーツ・お菓子 / 100227 食品
GENRE_IDS=215783,558944,551167,100227

# 1ジャンルあたりの候補数、レビュー平均の下限
PER_GENRE=3
MIN_REVIEW=4.0
room_tools.py候補の取得、記録、コピーを行う道具。Pythonの標準機能だけで動きます。
CLAUDE.mdClaudeが守るルール。投稿の自動実行などをしない約束が書かれています。
.claude/commands/room.md/room で始まる8つの手順。ファイルは、この場所に置きます。
困ったとき

よくある質問

「403」と出て、候補が取れません

アプリ登録で入れたURLと、.env の RAKUTEN_REFERER が一致していないことが多いです。最後のスラッシュまで同じにしてください。アプリIDとアクセスキーの貼り間違いも、あわせて確認します。

「429」と出ます

短い時間にアクセスしすぎた状態です。しばらく待ってから、もう一度 /room を実行します。続けて何度も実行しないでください。

候補が少ない、出てきません

表示済みの商品は記録で除かれるため、続けるほど減ります。GENRE_IDS にジャンル番号を足すか、MIN_REVIEW を少し下げると増えます。

Pythonがないと言われました

Claudeに「Pythonを入れる方法を教えて」と頼んでください。Windowsでは、python や py という名前で動くことがあります。

コピーがうまくいきません

クリップボードへのコピーは、Windowsでの動作を確認できていません。うまくいかないときは、画面に出た文章か、today フォルダの posts.txt から、自分で選んでコピーしてください。

Claudeが、使ったことにしてしまいませんか

しません。「使った」と扱われるのは、あなたが選んだ商品だけです。選ばなかった商品の投稿文は作られません。

写真も、AIで生成できませんか

このガイドでは扱いません。商品の画像をAIで作ると、使っていない商品を使ったように見せることになり、アカウントを守るうえで危険です。楽天の商品画像をもとにした生成も、同じ理由で外しています。撮影が負担なときは、Claudeが出す「撮影メモ」に沿って、1枚だけ撮ってください。

「今日の投稿を作って」だけで、投稿まで済みますか

候補の取得から、投稿文の下書き、記録の準備までは進みます。途中で、使った商品と感想を聞かれます。ROOMへの投稿は、あなたが自分の手で行います。

使ったことのない商品が出てきました

選ばないでください。選ばなかった商品の投稿文は作られません。

投稿文を直したいです

「もう少し短く」「やわらかい言い方に」のように頼むだけで直せます。直したあとも、書き方のルールは守られます。

画面の図は、キットの実際の出力をもとにした再現です。商品名、ショップ名、ID、URLはすべて見本で、実在のものではありません。

このガイドは、非公式の解説です。楽天グループとは関係がありません。規約は改定されることがあるため、投稿の前に、楽天アフィリエイトと楽天ROOMの最新のルールを確認してください。報酬の例や料率は、確認した時点の情報です。
